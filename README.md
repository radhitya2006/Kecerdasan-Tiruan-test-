# YieldPredict — kerangka awal

Setup ini hanya berisi struktur folder, file placeholder, dan dataset mentah.
Belum ada preprocessing, model terlatih, evaluasi, atau aplikasi yang berjalan.

## Struktur dan fungsi

| Path | Fungsi |
| --- | --- |
| app.py | Placeholder antarmuka Streamlit |
| train.py | Placeholder preprocessing, training, dan evaluasi |
| requirements.txt | Tempat daftar dependensi; belum diisi paket |
| data/raw/yield_df.csv | Dataset mentah; jangan diedit langsung |
| data/processed/ | Tempat data hasil preprocessing, masih kosong |
| notebooks/ | Tempat eksplorasi dan eksperimen awal, masih kosong |
| models/ | Tempat model terlatih nantinya, masih kosong |
| .gitignore | Mengabaikan virtual environment dan file sementara saat memakai Git |

## Dataset yang dipilih

[Crop Yield Prediction Dataset — Rishi Patel / Kaggle](https://www.kaggle.com/datasets/patelris/crop-yield-prediction-dataset)

File `yield_df.csv` sudah diletakkan di `data/raw/` dalam kondisi asli.
File ini merupakan versi gabungan yang tersedia dalam unduhan dataset; file sumber
lain dari arsip belum disertakan agar kerangka awal tetap sederhana.

## Membuka project di VS Code

1. Ekstrak ZIP.
2. Buka folder `YieldPredict` melalui File → Open Folder.
3. Untuk membuat virtual environment nanti, jalankan `python -m venv .venv`
   dari terminal di folder project dan pilih interpreter `.venv` di VS Code.

Belum ada perintah menjalankan aplikasi karena file Python masih placeholder.
Langkah berikutnya adalah mengecek dataset sebelum mulai menulis preprocessing.
